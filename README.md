# FlowSync

FlowSync is a project and task management backend built with
Node.js, Express.js, MongoDB and JWT authentication.

## 🚧 Project Status

**Status: In Development**

The backend foundation and authentication system are currently
implemented. Project and task management features are being built.

## ✅ Currently Implemented

- Employee CRUD APIs
- Search and filtering
- Pagination
- MongoDB integration
- Error handling
- User registration
- Password hashing with bcrypt
- User login
- JWT authentication
- Protected routes
- Role-based authorization

## 🔨 Currently Working On

- Project management
- Project members
- Task management
- Subtasks
- Project roles

## 🔜 Planned

- File attachments
- Refresh tokens
- Email verification
- Password reset
- React frontend
- Docker
- Deployment
